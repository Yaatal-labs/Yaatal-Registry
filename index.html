What is Yaatal?

EN

Yaatal is a suite of open-source AI tools built by Yaatal Labs. From agent orchestration with Paperclip to data annotation with Label Studio, a unified dashboard in Studio, and scalable inference through the upcoming Engine API — Yaatal gives teams an end-to-end toolkit for building, training, and deploying AI systems, all self-hosted and fully open source.

FR

Yaatal est une suite d'outils IA open source développée par Yaatal Labs. De l'orchestration d'agents avec Paperclip à l'annotation de données avec Label Studio, un tableau de bord unifié dans Studio, et l'inférence scalable via l'Engine API à venir — Yaatal offre une boîte à outils complète pour construire, entraîner et déployer des systèmes d'IA, entièrement auto-hébergés et open source.
